## Behavior and boundaries

Self-update rejects either guardian property, including explicit nulls. Administrator provisioning remains available; changing the parent phone clears a stale chat unless the administrator explicitly supplies the chat property. An explicit null chat resets the binding.

Telegram binding requires a private chat and the sender's own contact. The service normalizes ASCII phone digits and permitted formatting, matches the configured parent phone rather than the student's phone, and binds matching nondeleted student siblings together. Any conflicting existing sibling binding rejects the entire attempt. Rebinding requires an administrator reset. The repository selects candidates in ID order with PostgreSQL row locks, flushes binding changes, and leaves commit ownership with the caller. Both rejection and success replies occur after the database session closes.

Scope corrections were recorded in the task before implementation: repository interface/implementation paths keep SQL and locks in the repository; the existing webhook integration test now distinguishes student and parent phones. Frontend files remain read-only under the user's separate ownership instruction.
