## Resulting backend behavior

- Whole-tree `/storage` exposure is removed. Only `/storage/avatar` and `/storage/course` are public/cacheable; private legacy document paths return 404.
- `GET /api/v1/documents/{document_id}/download` authenticates before opening bytes and shares the existing listing policy: students own their documents, mentors see student documents and their own mentor documents, superadmins see all documents, and accountants are denied. Deleted records cannot be downloaded. Denied or missing objects return 404 without disclosing existence to other owners.
- Local reads resolve symlinks and reject root/traversal escapes. Document responses retain no-store caching; attachment filenames are quoted and invalid stored media types fall back to `application/octet-stream` rather than entering response headers.
- GCS document identifiers and legacy bucket URLs are redacted from metadata into the authenticated document-ID route. Private cloud operations require explicit enforced Public Access Prevention, reject public IAM bindings, and reject public object ACLs using actual SDK entity semantics. ACL-enabled uploads request a private ACL; uniform access avoids unsupported object ACL operations. Privacy-policy refusal becomes a generic 503 without private bytes.
- Existing document writes remain local, exactly as before WP-04, including when GCS is configured. This preserves the current local-only notification attachment workflow. Configured GCS supports reads/deletes of existing cloud identifiers while legacy `/storage/...` rows continue using local storage. Enabling new GCS document writes is a broader storage-injection change, not silently introduced here.

The original worker instantiates LocalStorageService directly and sends files up to 50MB as attachments. Earlier executor wording suggesting this worker called GoogleCloudStorageService.get_url was inaccurate. New document uploads are capped at 50MB and keep that attachment path intact. Historical larger-file notifications may contain now-obsolete public URLs; updating that worker's legacy link branch is outside this package's file scope.
